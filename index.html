📥 Import Master Barang

Upload file Excel/CSV berisi daftar barang untuk diimpor sekaligus ke Master Barang

Total barang di Master Barang saat ini: -

Baris pertama file harus jadi header kolom, minimal ada kolom nama dan satuan. Kolom kategori, barcode, dan stok (stok awal, angka) boleh ditambahkan (opsional). Nama kolom tidak case-sensitive. Kolom stok hanya untuk stok awal — kalau barangnya sudah ada, re-import tidak akan menimpa stok yang sudah berjalan kecuali kamu isi ulang kolom itu.
